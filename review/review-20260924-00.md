- [x] **E5 `?*T` 的 narrowing 不完整** —— `01-types.md` Nullability 段只定义

      结论：**两种都支持，且对所有 `?T` 一视同仁。**
      - 与 `None` 的比较在「比较成立的那一支」窄化，两个方向都算

      - 函数类型 `fn(A) -> B`；是普通指针（一字），`?fn(A) -> B` 可空
      - 闭包 `fn[captures](params) -> Ret { body }`（沿用用户的构想）

- [x] **E12 闭包要支持捕获指针** —— 只按值捕获写不了累加器（结果拿不回来）。
      结论：捕获列表支持 `&a`（`*T`）与 `&mut a`（`*mut T`），复用已有取地址运算符。
      安全约定与别的借用一致：`&mut` 触发排他性；闭包活得比被捕获者久 ⇒ debug 检查 /
      release UB（与切片同价）。
      **`Fn` / `FnMut` 的分界按 xyz 的机制划**：透过捕获的 `*mut T` 写 ⇒ 只要 `Fn`
      （可写性在指针类型里，从 `*Self` 读出即可）；透过 `self` 写（`mut` 按值捕获）
      ⇒ 需要 `FnMut`。**与 Rust 不同**（Rust 需从 `&mut self` 重新借出，故一律 `FnMut`），
      规范里明确注明了这个差异。
      已落地：`01-types.md` Closures 段、`05-traits.md` `## Fn` 段。
      状态：已定
- [x] **E7 顶层常量与全局变量未定义** —— `const` 只作为关联常量出现。
      结论：两级，语法沿用 Rust —— `const`（编译期值，无地址）/ `static`（有地址的
      全局槽位）/ `static mut`（可写）。
      最初建议「不要可变全局」（A），用户以「系统编程语言绕不开」为由否决，改采 B：
      - 初始化式必须编译期已知 ⇒ 顺带消除静态初始化顺序问题
      - **排他性不管 static**：任何函数都可读写，不检查不证明（明写，不留白）
      - **static 永不析构**：析构要「恰好一次」而无时刻可跑，故程序结束时直接放弃
      - 可见性走 `pub`；`const` 也可写在块内
      已落地：`01-types.md` 新增 `## Constants and statics`、`README.md` 的
      What xyz guarantees 补「Deliberately unchecked」一条。
      状态：已定

- [x] **E10 `*p` 的语义未定义** —— `01-types.md` 只写「`*p` reads the pointee and

- [x] **E11 `*mut T` 的排他性** —— 原设计允许 `*T` 与 `*mut T` 并存（C 式），
      代价是「不能通过指针析构」（`*p = v` 对 `Drop` 类型被拒）。
      结论：改为 **`*mut T` 排他** —— 存活期间，原绑定和其他指针都不可再用。
      检查方式选 **B**：函数内静态检查（与 `03` 的移动分析同源），跨函数无生命周期
      信息故为约定（debug 下检查、release 下 UB），与切片的处境一致。
      连带：`*p = v` 对 `Drop` 类型改为 ✅（旧值就地析构）；
      `03` 的 `@take` 示例去掉第二个指针（排他不允许多指针），并把「别名看到零值」
      的理由换成「所有者仍会看到并析构它」；「从位置移出」的理由换成
      「位置不拥有值，绑定才拥有」。
      已落地：`01-types.md`（新增 Exclusivity 小节、`*p` 写规则、编译期检查清单）、
      `03-move.md`（Assignment 段、Moving Out of a Place 段、Take 段）。
      状态：已定
- [x] **E9 错误处理模型未定义** —— 只有 debug trap / release UB 与 `?T`；
      没有 `Result`、没有显式 panic/abort。
      结论：**`Result` 方案 + 与 `Option` 同源的糖**。
      - `?` 读作「或者」：`?T` = `Option<T>`（或者没有），`E?T` = `Result<T, E>`（或者 E）
      - `Result` 是 std 里的普通枚举，变体沿用 `Ok` / `Err`
      - **传播操作符 `f()?`**：取值，或把错误提前返回；仅在函数结果为同 `E` 的 `E?T` 时可用
      - 窄化与 `?T` 共用规则，改成与 `Err` 比较；要拿到 `e` 用 `match`
      - 布局：niche 复用扩展到 `E?T`（两者中谁有多余位模式就用谁）
      - **`panic` 假定为 std 里的普通函数**，不是 builtin
      已落地：`01-types.md`（`### Results` / `### Propagation`）、`05-traits.md`
      （`## Result`）、`02-layout.md`（niche 规则）、`08-reflection.md`（TypeInfo 分流）。
      状态：已定
